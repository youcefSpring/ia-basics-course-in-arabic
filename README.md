دروس وعروض تقديمية وسلاسل أعمال موجهة لمقياس الذكاء الاصطناعي التوليدي،
مكتوبة بـ LaTeX باللغة العربية.

المدرسة العليا للأساتذة ببوزريعة — ملحقة بومرداس
الأستاذ: د. بن عبد الرزاق يوسف

## هيكل المستودع

- `Courses/` : ملفات الدروس بصيغة PDF، ومصادرها في `Courses/tex/`.
- `slides/` : العروض التقديمية (Beamer)، مع ملف التنسيق المشترك `style.tex`.
- `Series/` : سلاسل الأعمال الموجهة لكل فصل.
- `presentation_tex_template/` : قالب العرض التقديمي مع صورة معاينة.
- `fonts/` : الخطوط المستعملة (Amiri و AlBattar).

## سلاسل الأعمال

- تتكون كل سلسلة من نشاطين على الأقل.
- **النشاط الثاني في كل سلسلة هو دائما واجب منزلي**، يُنجزه الطالب في المنزل
  ويُسلّمه في الحصة القادمة. يظهر ذلك في عنوان النشاط:
  `النشاط الثاني (واجب منزلي): …`
- السلسلة السابعة عبارة عن مخبر تطبيقي من عدة أنشطة متتالية، ونشاطها الثاني
  (تحضير الملف المرجعي) واجب منزلي كذلك.

## الترجمة (Compilation)

تُترجم كل الملفات بـ XeLaTeX أو بـ tectonic، لأنها تعتمد على الحزمة
`polyglossia` والخطوط العربية.

```bash
# سلاسل الأعمال
cd Series && tectonic wajib3.tex

# العروض التقديمية
cd slides && tectonic dars3_slides.tex
```

### الخطوط

إذا لم يكن الخطان Amiri و AlBattar مثبتين في الجهاز، تُحمَّل الملفات تلقائيا
من المجلد `fonts/`، فلا حاجة إلى تثبيتهما.

ملاحظة: تُكتب العناوين ورأس الصفحة وتذييلها بالأمر `\khatt` بدل `\sffamily`،
لأن `\sffamily` يفقد الخط العربي بعد استعمال `\textenglish`، فتظهر
العناوين فارغة.
